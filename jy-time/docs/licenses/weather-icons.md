# Weather Icons

Simple Pixel Style includes a small weather-condition subset from Weather Icons:

- Source project: https://github.com/erikflowers/weather-icons
- Original icon designs: Lukas Bischoff
- Icon art from v1.1 forward, HTML, Less, and CSS: Erik Flowers
- Upstream license for Weather Icons: SIL Open Font License 1.1

Included source SVGs:

- `resources/images/weather/weather-icons/source/wi-day-sunny.svg`
- `resources/images/weather/weather-icons/source/wi-day-cloudy.svg`
- `resources/images/weather/weather-icons/source/wi-cloudy.svg`
- `resources/images/weather/weather-icons/source/wi-fog.svg`
- `resources/images/weather/weather-icons/source/wi-rain.svg`
- `resources/images/weather/weather-icons/source/wi-snow.svg`
- `resources/images/weather/weather-icons/source/wi-thunderstorm.svg`

The Pebble bitmap resources in `resources/images/weather/weather-icons/small/`
and `resources/images/weather/weather-icons/large/` are monochrome raster
conversions of those SVGs for the watchface complication layout.
