# Simple Pixel Style 0.67

- Fixes the 0.66 conditional menu — Per-Section Colors stayed visible in Black & White mode (and the other conditional sections were similarly inert) because the Clay customFn was relying on module-scope constants that didn't survive serialization into the config page. All the section-key lists and helpers now live inside `customClay`, so the hide/show logic actually runs in the settings UI.
- Adds a "Half-hour timeline pips" toggle to the Your Day overlay (in the Shake → Your Day settings). When on, each hour pip splits into halves: events at X:00 to X:29 fill the left half, events at X:30 to X:59 fill the right half, and hours with events spanning both halves stay fully filled. Empty hours still show as a hollow circle. Off by default — flip it on to get the finer-grained read on your day.
- Bumps the AppMessage inbox from 256 to 512 bytes to fit the additional half-hour bitmaps the calendar bridge now sends.
- Brings back the timeline pip for the current hour — it had been suppressed in favor of the elbow bracket pointing at the "Now: X:XX" line. The current-hour pip now follows the same full / left-half / right-half / hollow rendering as every other hour. The elbow line starts just below the pip's bottom edge instead of cutting through it, so the two elements don't overlap. The hour-number label is suppressed for the current hour since the elbow already points at the time text below.
- Adds a "No-events label" text input in Calendar settings (default `[None]`, up to 24 characters). It drives the placeholder shown on the main face meeting bar, the Your Day "Next:" line, and the Upcoming shake overlay when there's nothing scheduled. Pick whatever language you want — empty input falls back to `[None]`.
