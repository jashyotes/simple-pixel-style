# Simple Pixel Style 0.72

- Adds the **Tide chart** shake overlay — a sinusoidal NOAA-driven water-level curve for a chosen US coastal station. Configure a NOAA station ID (find yours at tidesandcurrents.noaa.gov) and choose feet or meters in Calendar → Shake → Tide chart settings. The overlay shows the next 24 hours of predicted water level, the next high tide and next low tide times and heights, and a dotted now-indicator. Network refresh runs on the existing weather refresh cadence — no second timer.
- Adds the **Halcyon Day View** shake overlay — a 24-hour ring with day hours rendered lighter than night hours, sunrise/sunset tick marks on the outside of the ring, hourly weather icons placed at 0/3/6/9/12/15/18/21 inside the ring, and a sun marker that tracks the current time around the ring. Inspired by the Halcyon watchface (github.com/freakified/halcyon).
- Fixes the byte-array AppMessage tuple bug that broke 0.70: the hourly weather codes and hourly tide levels were being sent as `Uint8Array` instead of plain JavaScript arrays. PebbleKit JS silently fails the entire dict serialization when it sees a typed array, which killed weather on the main face, killed the tide overlay, and starved the Halcyon ring of weather data. Both helpers now return plain arrays of integers. The watch-side byte-array tuple handling and the `[24]` length suffix in package.json messageKeys were already correct; only the JS-side payload type needed to change.
- Internal: the `weather_icon_for_code()` helper was refactored to a value-taking `weather_icon_for_code_value(uint8_t code)` so the Halcyon ring can map each hour's code to the right small bitmap. The original function delegates to the new one — all existing callers (main face complications, verbose weather, existing shake overlays) are untouched.
