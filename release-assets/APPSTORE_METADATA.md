Name: Simple Pixel Style

Version: 0.31

Category: watchface

Description:
Pixel-watch-inspired information-dense watchface for Pebble Time 2. Shows watch battery, Bluetooth status, full date, AM/PM time, a default top walking-man step counter, three configurable complication circles, and an optional bottom calendar event. Weather uses Open-Meteo through PebbleKit JS, and the bottom event can use a private iCal/ICS feed URL.

Release notes:
0.31 adds a Casio-style thousands comma to the default top W800 step counter. The comma is drawn low under the digit baseline so five-digit step counts stay readable without crowding the watchface header.
