Name: Simple Pixel Style

Version: 0.1.0

Category: watchface

Description:
Pixel-watch-inspired information-dense watchface for Pebble Time 2. Shows watch battery, Bluetooth status, full date, AM/PM time, steps, heart rate, weather, rain chance, and an optional bottom calendar event. Weather uses Open-Meteo through PebbleKit JS, and the bottom event can use a private iCal/ICS feed URL.

Release notes:
Initial Pebble Time 2 / emery watchface release with Pebble-app settings for layout, weather, and optional iCal/ICS calendar events. The native Android companion is not required for the Pebble Appstore PBW and is deferred.
