Name: Simple Pixel Style

Version: 0.35

Category: watchface

Description:
Pixel-watch-inspired information-dense watchface for Pebble Time 2. Shows watch battery, Bluetooth status, full date, AM/PM time, a default top walking-man step counter, three configurable complication circles, and an optional bottom calendar event. Weather uses Open-Meteo through PebbleKit JS, verbose weather can replace the circles, and the bottom event can merge one or two private iCalendar/ICS feed URLs.

Release notes:
0.35 includes the 0.34 Google Calendar fixes for recurring events, timezone handling, full event times, and 15-minute current-meeting rollover. It also adds an optional second iCalendar URL and always shows the soonest event across both calendar feeds.
