Simple Pixel Style 0.1.0

Initial Pebble Time 2 / emery release.

- Pixel-watch-style black-and-white watchface structure.
- Watch battery, Bluetooth status, date, AM/PM, time, steps, BPM, weather, rain chance, and optional bottom calendar event.
- Optional top W800-style step-counter layout can be enabled from the Pebble app settings.
- Weather settings support current phone location or manual coordinates, using Open-Meteo through PebbleKit JS.
- Bottom event row can be populated from a private iCal/ICS feed URL.
- Android companion support is deferred and is not required for this Pebble Appstore PBW.
